Dev notes

  • Panel structure: identical to the Ecommerce Website Development panel — same left rail, same 3-column grid, same 34px column gap. No panel header and no per-column headers; the links start at the top of the panel.
  • Link styling: 14px / weight 500 / navy, hover to orange. Slightly heavier than the Shopify sub-links because these are top-level links, not children.
  • Top alignment: with no header row, the first link sits higher than the Shopify menu's first sub-link. Panel padding is 26px top — nudge it if the two menus need to line up on hover-switch.
  • Naming: "Account Management" renamed to Amazon Account Management so every link carries the prefix — matches the page's own H1.
  • Left rail: "Amazon Marketing" should link to the /amazon-marketing/ hub, matching how the rail behaves on the Ecommerce side.
  • Panel height: 4-row columns fit in the same vertical space the current 4-link Amazon menu uses — no change needed to the dropdown shell or the nav's hover area.
  • Mobile: the same 11 links stack as a single accordion list under "Amazon Marketing" — no columns below the tablet breakpoint.
